# 第 22 课：轻与重 — 同样的力，谁的加速度大？

## 课程目标

21 课我们用 F=ma 从力算出了速度；这一课把 F 固定、只变 m，看另一半
规律 **a = F/m**：同样的力推轻球和重球，轻球加速度大——质量是
「对加速的抗拒」（惯性）。

顺带学两个工程手段：`add_extra_weight` 给物体配重（公共质量接口，
配重后读数与物理响应均实测精确命中）、`set_geom_friction` 关摩擦
（先造一个"无摩擦世界"把变量隔离干净——摩擦是下一课的主角）。

## 本课概念

- **a = F/m**：同样的力，质量越大加速度越小。末速 v = F/m·t，
  两球速度比 = 质量反比（4 倍质量 → 1/4 速度）
- **质量是内在属性**：两个外观完全相同的球，质量可以差 4 倍——
  配重接口不改形状只改质量，正好把"质量"从"大小"里剥离出来看
- **控制变量**：想干净验证 a=F/m，就得把摩擦关掉——否则摩擦力
  μmg 也和质量有关，两个变量搅在一起。物理实验的黄金法则：
  一次只让一个变量变
- **无摩擦世界**：MuJoCo 接触摩擦取两 geom 的**逐项最大值**，所以
  地面和两球**都要**降——只降一边等于没降；且要降就降到**精确 0**
  （留 ~0.001 的残余，球会从滑动慢慢转向滚动，比值会漂）
- **惯性（牛顿第一定律）**：撤力后两球匀速前进，速度不再变化——
  没有力，就没有速度的变化

## 关键代码

```python
# 配重：按实测质量补差值，倍数永远精确（公共质量接口，已实测验证）
env.add_extra_weight({heavy: (HEAVY_RATIO - 1.0) * m_light})

# 无摩擦世界：地面 + 两球的 geom 摩擦都降到精确 0（逐项最大值，两边都要降）
env.set_geom_friction({geom: np.array([0.0, 0.0, 0.0]) for ...})

# 同样的力并排推两球——只有 m 不同
for ball in (light, heavy):
    env.apply_body_force(ball, np.array([PUSH_FORCE, 0.0, 0.0]), np.zeros(3))
```

## 预期结果与解释

- 终端实测打印两球质量比 1:4（配重后复读确认），预测末速 ≈ 0.57 / 0.14 m/s
- 施力段每 0.5s 播报：轻球一路领先，两球各自与 F/m·t 理论爬升精确吻合
- **末速比 ≈ 4.0 = 质量反比**；撤力后惯性窗里两球匀速
- 直观记忆：卡车 vs 自行车，同样的推力推同样的时间，自行车快得多
  ——不是力偏爱轻的，是 m 在分母上

## 常见问题

| 现象 | 原因与处置 |
|---|---|
| "未找到两个球或地面" | 自摆场景缺件：拖两个球 + 地面，或加 `--default-scene` |
| 球打转/轨迹歪 | 视口拖拽干扰（ActorManipulator）——重跑，运行期间手离开视口 |
| 末速比漂到 4.5+ | 摩擦没降到精确 0（球从滑动转了滚动）——确认 `--default-scene` 与脚本版本 |

## 动手改

配方区 `PUSH_FORCE = 0.4` → `0.8`：力加倍，两球末速都加倍，比值不变；
`HEAVY_RATIO = 4.0` → `2.0`：重球变轻（缩放变小），末速变 2 倍。
