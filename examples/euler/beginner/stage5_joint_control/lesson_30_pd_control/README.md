# 第 30 课：手写 PD 控制器（阶段 5 毕业课）

## 本课效果
同一个目标角 30°，三组参数各走一遍：欠阻尼（kv=0.5）冲过头弹回来，
超调 ≈54%、来回振荡；过阻尼（kv=10）一路刹车慢慢爬，8 s 才勉强
站稳；临界阻尼（kv=2.6）无超调、≈1.5 s 收敛——三组里最快。27 课
那台「内部有弹簧」的电机，内核被你用两行公式复刻了。

## 准备

29 课同款教具）。

## 关键代码
PD 的全部——每个控制拍先读状态（反馈），再算力矩：
```python
q = env.data.qpos[qadr]          # 当前角度（P 的原料）
w = env.data.qvel[vadr]          # 当前角速度（D 的原料）
ctrl[0] = KP * (target - q) - kv * w   # 弹簧 + 阻尼
env.do_simulation(ctrl, sim_link.FRAME_SKIP)
```
- **P（比例）= 弹簧**：误差越大力越大，把旋臂往目标拉——27 课静差
  的根源（误差为零力为零，所以永远留一点误差扛负载）
- **D（微分）= 阻尼**：转得越快刹得越猛，把振荡的能量抽走
- 配比是命门：阻尼比 ζ = kv/(2√(kp·I))。ζ<1 欠阻尼（振荡）、ζ>1
  过阻尼（迟缓）、ζ≈1 临界（无超调最快）

## 动手改
配方区 `KV_CRIT = 2.6` → `2.0`（ζ≈0.78）：带 ~3% 微超调，但见到 2%
误差带比临界更早——工程上「最快收敛」常取 ζ≈0.7；`TARGET_DEG =
30.0` → `90.0`：步进变大，三组性格不变（线性系统的尺度不变性）。

## 解释结果
- **欠阻尼超调 54%**——冲到 46° 才被 D 拉住弹回；理论
  exp(−πζ/√(1−ζ²))，ζ=0.19。荡秋千不收腿就是这个曲线
- **过阻尼 8 s 爬不完**——D 太强，误差按慢极点 λ=ωn(ζ−√(ζ²−1))
  ≈0.51 的指数尾巴衰减：门卫式的「绝不越界，但磨蹭」
- **临界 ≈1.5 s 收敛**——理论 ≈5.8/ωn；工程默认的首选性格
  （要再快见 2% 误差带，得允许一点超调，见「动手改」）
- **30° 的选择是伏笔**——26 课上帝模式一步掰到 30°，本课 PD
  「走」到 30°：前者改读数、后者出力气，阶段 5 的毕业对照
- **27 课电机 = 本课公式**——那台 kp=100、kv=8 的位置伺服，拆开
  就是 τ = kp·误差 − kv·角速度。你以为在「发目标角」，其实是
  电机里的 PD 替你跑这套循环

## 常见问题
| 现象 | 修复 |
|---|---|
| 报错 nu=0 | 场景里的旋臂没有执行器——本课需要 rotor_torque（拖入或 --default-scene） |
