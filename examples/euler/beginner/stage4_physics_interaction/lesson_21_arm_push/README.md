# 第 21 课：臂式推放

## 本课效果
臂慢扫 9 秒把球从 45° 方位一路推走 0.6m——幕 1；场景复位后绕开臂，
一只「无形的手」（apply_body_force）用 0.2N 推 2.5 秒——终端每
0.5s 播报实时速度，看得见球从静止一步步爬到 0.23 m/s，撤力后靠
惯性再滚 2 秒——幕 2。两幕的对比：臂推慢而稳（臂多快球多快），
直推快而自由（力想多大就多大）。

## 准备
同第 19 课（OrcaPlaygroundAssets 订阅，含积木臂、球、桌子）。

## 运行
```bash
python -m examples.euler.beginner.stage4_physics_interaction.lesson_21_arm_push.run --default-scene
```

## 关键代码
两种推动方式的代码对照——
臂推（运动学链 + 接触力，19/20 课技能）：
```python
qpos[qadr] = rate_rad * t          # 肩关节脚本：梁端线速度 = ω·r
qpos[e_qadr] = 0.0                 # 肘钳定 0°（19 课：不锁会被球反踢弯）
env.do_simulation(ctrl, sim_link.FRAME_SKIP)   # 梁面持续推球前进
```
直推（外力，本课新 API）：
```python
env.apply_body_force(ball, np.array([fx, fy, 0]), np.zeros(3))  # 持续合力
env.do_simulation(...)            # F=ma：力 → 加速度 → 速度逐步积累
env.clear_body_force(ball)        # 撤力（惯性还在——牛顿第一定律）
```
本质区别：臂推的球速封顶于梁上接触点的线速度（v=ωr，接触点在梁
中部、半径比梁端小）——臂多快球多快；直推的球速 ≈ F/m×t（合力
持续积累）——力是自由参数，想慢就减力、想快就加力。

## 动手改
配方区 `SWEEP_RATE = 10.0` → `20.0`：臂扫快一倍，球速约翻倍；
`PUSH_FORCE = 0.2` → `0.4`：直推力加倍，撤力时球速约加倍（终端
的实时播报会看得更明显）。

## 解释结果
- **幕 1 用慢档 10°/s**——快档（30°/s）全程仅 3s、接触后一瞬就
  结束，推动过程根本看不清；慢档 9s 里球被梁面持续推行 0.6m，
  「被动被推」的节奏一目了然
- **幕 1 球速 ≈ 0.04 m/s**——梁端线速度 ω·r = 0.17×0.385 ≈ 0.07 m/s，
  但球是被梁**中部**的侧面推着走（接触点半径 < 梁端半径，19 课
  「球心圆 > 接触点圆」同款几何），实测介于接触点速度与梁端速度之间
- **幕 2 撤力后球速 ≈ 0.25 m/s**——F=ma 积分一次：v ≈ F/m×5/7×t
  （5/7 是球滚动因子，球从静止加速时力有一部分花在让它滚起来）；
  施力段终端每 0.5s 播报一次实时速度（0.03→0.08→0.13→0.18→0.23），
  「合力积累速度」的线性爬升直接看得见——与幕 1 的「被动被推」
  形成节奏对比；撤力后惯性窗 2s 里球再滚 ~0.5m（牛顿第一定律）
- **两次方向相同**——幕 2 的推力方向取球所在方位的切线方向，
  和臂扫掠推球的方向一致：公平对比
- **外力是持续状态**——apply 一次后一直在，必须 clear 才撤；本课
  撤力后球靠惯性继续滚，结束时再 clear_all_forces 兜底

## 常见问题
| 现象 | 修复 |
|---|---|
| 幕 1 臂没碰到球 | 球须在扫掠弧线上（默认配方摆 45° 方位 r=0.30）——用 --default-scene |
| 幕 2 球速和理论差不少 | 桌面摩擦参数影响 5/7 因子的准确度；量级对了即可，精确摩擦建模在后续课程 |
| 球被推出桌外 | 视口拖拽干扰或参数改得过大——运行时手离开视口，力别超过几牛 |
| 下次运行球自己动 | 本课结束已 clear_all_forces()；若中途 Ctrl+C 退出，重连后由复位清除 |
| 幕 2 方向和幕 1 不一致 | 自摆场景时球若不在 45° 方位，切线方向按实际方位计算——看日志里的方向向量 |
