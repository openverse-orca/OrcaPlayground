# 第 12 课：删除与恢复

## 本课效果
把指定方块的名字填进配方区 `DELETE_NAMES`，重跑后它从场景消失；
清空再跑，它又回来了。阶段 2 的收官课。

## 准备
- 同第 01 课（OrcaLab + OrcaPlaygroundAssets 订阅 + 首次重启）
- ⚠️ 本课**重建教学场景**：每次运行会清空场景再摆放（不是热编辑）

## 运行
```bash
python -m examples.euler.beginner.stage2_scene_editing.lesson_12_delete_object.run
```

## 关键代码
`run.py` 顶部的**配方区**就是你要改的地方：
```python
# ======================= 配方区（改这里） =======================
DELETE_NAMES: tuple[str, ...] = ()
# ================================================================
```
基础配方是三颗方块（`block_1/2/3`）。`build_recipe()` 会跳过
`DELETE_NAMES` 里点名的实例——**删除 = 从配方里移除条目**。

## 动手改
把 `()` 改成 `("block_2",)`，重新运行，中间的方块消失；
再改回 `()`，重新运行，它恢复原位。

## 解释结果
- 配方是场景的**唯一事实源**：删了配方条目，物体就没了；条目还在，
  物体就永远能原样重建。你在这 6 课里做的所有事——移、转、缩、
  换色、复制、删除——本质上都是同一件事：**改配方，再重建**。
- 注意删除的是**条目**不是文件：资产还在库里，随取随用。
  填错名字（如 `block_5`）会直接报错并列出可删名单，不会默默失败。

## 小挑战
一次删除两颗（`("block_1", "block_3")`），重跑后场景里剩下谁？

## 阶段 2 毕业挑战 🎓
搭一个**九宫格方块阵**，再玩「消消看」：
1. 参考第 11 课的循环，改 `build_recipe()` 生成 3×3 方块阵
   （实例名沿用 `block_行_列` 规则）
2. 把正中间那颗（`block_2_2`）填进 `DELETE_NAMES`，重跑——
   阵型中心空一格
3. 清空 `DELETE_NAMES` 再跑——九宫格完整如初

> 验收：视口先看到 9 颗 → 再看到缺中心的 8 颗 → 最后恢复 9 颗。
> 你已经会：移/转/缩/换色/复制/删除——场景编辑的全部基本功。

## 常见问题
| 现象 | 修复 |
|---|---|
| 报"未知实例 1/_/b/c/k..." | 单个名字少写尾逗号：`("block_1")` 是字符串，`("block_1",)` 才是元组 |
| 报"未知实例" | `DELETE_NAMES` 只能填基础配方里有的名字（block_1/2/3） |
| 删除后其他方块动了 | 重建会复位全部物体（PublishScene 语义），不是只删一颗 |
| 恢复不了 | 确认 `DELETE_NAMES` 已清空为 `()` 并保存重跑 |
