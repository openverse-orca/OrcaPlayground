# 第 23 课：光滑与粗糙 — 摩擦如何"吃掉"运动

## 课程目标

22 课我们把摩擦关到 0 验证了 a=F/m（撤力后永远匀速）；这一课把
摩擦**请回来当主角**：两个相同的小方块，同样的 1.0 m/s 初速度，
一个"鞋底"光滑（μ=0.05）、一个粗糙（μ=0.6）——滑行距离差一个
数量级：

    d = v² / (2·μ·g)    —— 距离与初速度平方成正比、与 μ 成反比

顺带一个反直觉发现：公式里**没有质量**——轻块重块滑得一样远
（22 课的 m 和这里的 μ 各管各的）。

新工程手段：`set_joint_qvel` 直接写状态造初速度（不用力去推——
踢一脚的施力时长不可控，写状态才能保证两块起点条件完全相同）。

## 本课概念

- **d = v²/(2μg)**：摩擦力 μmg 把动能 ½mv² 一点点换成热。μ 大一倍，
  减速 g·μ 快一倍，距离短一半；初速度大一倍，距离翻两番（平方！）
- **公式里没有 m**：摩擦力随质量变大，但减速效果 μg 与质量无关——
  惯性大刹车也大，正好抵消。和 22 课对着看：**质量管加速，摩擦管刹车**
- **逐项最大值**：MuJoCo 接触摩擦取两 geom 的逐项最大值——两块躺
  在同一块地上，差别全在方块自己的"鞋底"（地面统一 0.05，配对时
  取 max，粗糙块的 0.6 才能生效）
- **写状态 vs 施力**：`set_joint_qvel` 直接写初速度，比"踢一脚"
  （apply_body_force）可控——踢的时长不可控，写状态才能保证
  对照实验起点条件完全相同

## 关键代码

```python
# 两档"鞋底"：地面统一 μ=0.05，光滑块 0.05、粗糙块 0.6（配对取 max）
env.set_geom_friction({geom: np.array([mu, 0.004, 0.0003]) for ...})

# 写初速度：set_joint_qvel 全量数组 + 自由关节 dof 地址（前 3 槽线速度）
qvel[dof : dof + 3] = np.array([speed, 0.0, 0.0])
env.set_joint_qvel(qvel)

# 并行观察两块滑行——粗糙块半秒就停，必须同时看，否则它早停在终点
```

## 预期结果与解释

- 发车后粗糙块 ~0.1 m 半秒内停、光滑块 ~1 m 滑约 2 秒才停
- 滑行距离与 d=v²/(2μg) 理论值各自吻合（1.02 m / 0.09 m），
  距离比 ≈ 12 = μ 反比
- 直观记忆：冰面 vs 柏油路，同样的车速刹停距离差一个量级；
  车速加倍，刹停距离翻四倍——这就是为什么高速限速

## 常见问题

| 现象 | 原因与处置 |
|---|---|
| "未找到两个小方块或地面" | 自摆场景缺件：拖两个小方块 + 地面，或加 `--default-scene` |
| 方块翻滚而不是滑行 | 视口拖拽干扰或场景里有其他物体挡路——重跑 / 清场 |
| 光滑块 4 秒没停 | μ=0.05 下 1 m/s 理论滑 1.02 m（约 2s），超过太多说明摩擦没降下去——检查 `--default-scene` 是否用了 |

## 动手改

配方区 `INIT_SPEED = 1.0` → `2.0`：初速加倍，两块距离都变 4 倍；
`MU_ROUGH = 0.6` → `0.3`：粗糙块鞋底变滑，距离变 2 倍。
