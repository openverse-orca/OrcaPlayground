# 第 16 课：修改重力

## 本课效果
同一块方块从同一高度落下三次：地球重力 0.4 秒内砸地，月球重力慢悠悠
约 0.8 秒，零重力原地漂浮。物理世界的"时间刻度"被你一行代码改写了。

## 准备（二选一，体现你的主导权）
- **你的场景（倡导）**：沿用前面课摆好的方块
- **兜底**：加 `--default-scene`，脚本用默认配方（地面 + 抬高一米的方块）

## 运行
```bash
# 方式 A：用你自己的场景
python -m examples.euler.beginner.stage3_simulation_time.lesson_16_change_gravity.run

# 方式 B：默认配方兜底
python -m examples.euler.beginner.stage3_simulation_time.lesson_16_change_gravity.run --default-scene
```

## 关键代码
```python
env.sim_config.gravity = np.array([0.0, 0.0, -1.62])   # 月球
sim_link.reset_env(env)                                 # 换重力后复位再实验
```
`sim_config` 是物理参数的官方入口（重力 / 步长 / 积分器）——改参数
**走配置，不戳引擎内部**。月球 g=1.62 是地球的 1/6，落地时间变成
√6 ≈ 2.5 倍（t = √(2h/g)）。

触地判定看**高度的单拍位移**（上一拍还在快速下落、这一拍骤停即触地）——
不同尺寸方块落地后 body 中心高度不同，硬编码高度阈值会误判。

## 动手改
配方区 `GRAVITY_SCENES` 加一组 `("火星", 3.71)`：预测一下火星落地
时间是地球的几倍，再运行验证；`FALL_TIME` → `5.0`：让月球组从容落地。

## 解释结果
落地时间反比于重力的平方根——重力小 6 倍，落地时间约变为 √6 ≈ 2.5 倍。
这就是仿真做参数实验的优势：**同一场景、同一初始状态，只动一个旋钮**。
真实世界里你可没机会换个星球。

## 小挑战
**预测落地时间**：把配方区只留 `("月球", 1.62)`。先估算方块的下落距离
（起点高度减去大约半个方块的静置高度），用 t = √(2Δz/1.62) 算出预测值
写在纸上，再运行对照实测触地时间，误差超过 0.2 秒就回本课"解释结果"
检查公式。

## 常见问题
| 现象 | 修复 |
|---|---|
| "未找到方块" | 拖入/自 spawn 一个含 "cube" 名字的方块，或加 `--default-scene` |
| 日志时间对但视口下落快慢不一致 | 已知架构限制：重力修改仅本地物理生效（无远端下发通道），Studio 视口按独立物理状态渲染；以日志时间和触地判定为准 |
| 零重力组没现象 | 方块会停在起点漂浮——这正是预期结果 |
