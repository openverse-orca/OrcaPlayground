# 第 09 课：缩放物体

## 本课效果
同一个绿色方块以 0.5、1、2 倍三种大小并排显示，直观对比缩放效果。

## 准备
- 同第 01 课（OrcaLab + OrcaPlaygroundAssets 订阅 + 首次重启）
- ⚠️ 本课**重建教学场景**：每次运行会清空场景再摆放（不是热编辑）

## 运行
```bash
python -m examples.euler.beginner.stage2_scene_editing.lesson_09_scale_object.run
```

## 关键代码
`run.py` 顶部的**配方区**就是你要改的地方：
```python
# ======================= 配方区（改这里） =======================
SCALES: tuple[float, ...] = (0.5, 1.0, 2.0)
SPACING_M: float = 2.5
# ================================================================
```
`scale` 是**等比缩放**乘数：0.5 = 整体缩小一半，2.0 = 整体放大一倍。
注意它不能分别调长宽高——想变成长方体，要用第 08 课那样的长方体资产。

## 动手改
把 `SCALES` 里的 `1.0` 改成 `1.5`，重新运行，中间那颗变大半倍。

## 解释结果
- 每颗方块的离地高度是代码按 `半高 × scale` 算的（不是手填的），
  所以不管怎么改倍数，方块都刚好贴地——这是「缩放会改变占用空间」
  的直接体现。
- 间距 `SPACING_M` 是中心距：2 倍方块宽 2 米，间距太小会互相穿插，
  放大倍数时记得同步放大间距。

## 小挑战
把中间那颗（原尺寸）换成 `1.5` 倍，再看看三颗还挤不挤——
如果穿插了，把 `SPACING_M` 也调大。

## 常见问题
| 现象 | 修复 |
|---|---|
| 方块互相穿插 | 倍数放大后占用变大；把 SPACING_M 调大 |
| 大方块悬空 | 离地高度由代码自动计算，若仍异常检查是否误改了 `_BLOCK_HALF_Z` |
| 缩放没生效 | scale 只在 spawn 时生效，确认已保存并重跑（重建场景） |
