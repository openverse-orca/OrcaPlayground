# 第 08 课：旋转物体

## 本课效果
一根蓝色长方体绕 Z 轴（竖直轴）转 45°。修改配方区角度后重跑，长边指向立即变化。

## 准备
- 同第 01 课（OrcaLab + OrcaPlaygroundAssets 订阅 + 首次重启）
- 本课使用资产 `cuboid_usda`（1.2×0.2×0.2 m 长方体）
- ⚠️ 本课**重建教学场景**：每次运行会清空场景再摆放（不是热编辑）

## 运行
```bash
python -m examples.euler.beginner.stage2_scene_editing.lesson_08_rotate_object.run
```

## 关键代码
`run.py` 顶部的**配方区**就是你要改的地方：
```python
# ======================= 配方区（改这里） =======================
CUBOID_ROTATION_DEG: tuple[float, float, float] = (0.0, 0.0, 45.0)
# ================================================================
```
三个数依次是绕 x / y / z 轴的角度（单位：度）。第 3 个数绕 Z 轴——
就是站在地面上原地转向的那个轴。

## 动手改
把 `45.0` 改成 `90.0`，重新运行，长边从斜着指向变成正对 X 轴。

## 解释结果
- 为什么用长方体不用方块：方块四面对称，转 45° 看不出任何变化；
  长方体有长边，朝向一目了然。
- 你写的是角度（度），spawn 接口用的是四元数——转换已收口在
  `scene_recipe` 助手里（FR-A07），所以你永远不用操心 wxyz/xyzw。

## 小挑战
先把 `45.0` 改成 `90.0`，**在运行前猜**：长边会指向世界坐标的哪条轴、
和 X 轴夹角多少度？再运行验证你的猜测。

## 常见问题
| 现象 | 修复 |
|---|---|
| 转了没反应 | 确认改的是第 3 个数（Z 轴）；改的是配方区常量并保存 |
| 长方体悬空/穿地 | 位置 z 应保持 0.1（半高）；绕 x/y 轴大角度旋转会改变占地高度 |
| 报错"资产包未订阅" | `cuboid_usda` 为新增资产，需先发布到资产库并重启 OrcaLab |
