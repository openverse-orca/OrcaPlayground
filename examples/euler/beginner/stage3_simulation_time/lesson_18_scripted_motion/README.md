# 第 18 课：让物体沿路径移动（阶段 3 毕业课）

## 本课效果
方块沿圆轨迹平滑绕圈——不是被推、不是落下，而是你每帧写下它的位姿。
`--moon` 模式则是毕业挑战：预测月球落点时间，实测揭晓。

## 准备（二选一，体现你的主导权）
- **你的场景（倡导）**：沿用前面课摆好的方块（需要能自由运动的物体）
- **兜底**：加 `--default-scene`，脚本用默认配方（地面 + 抬高到三米的方块）

## 关键代码
```python
joint_name, qadr = sim_link.resolve_free_joint(env, block_name)  # 按名称解析地址
qpos = np.asarray(env.data.qpos).copy()
qpos[qadr:qadr+3] = (x, y, z)          # 写入目标位置（圆轨迹）
env.set_joint_qpos(qpos)                # 全量写回
env.mj_forward()                        # 更新派生量
env.render()                            # 推送视口
```
三个要点：
1. **不假定 qpos 布局**——先按名称解析自由关节地址，写哪个 slice 由解析决定
2. **写完位置把速度清零**——纯运动学写入不带动量（"按模型规范处理速度"）
3. **这是瞬移式跟随**——物体没有受力，也不响应碰撞（阶段 4 的动力学会形成对比）

## 动手改
配方区 `AMPLITUDE = 0.4` → `0.8`：圆画得更大；`PERIOD = 4.0` → `2.0`：
转速翻倍；把 `(sin, cos)` 对调成 `(cos, sin)`：反方向绕圈。

## 解释结果
运动学写入是"摆pose的连续版"（第 02 课摆一次，这里每帧摆一次）；
力与碰撞则是"让物理替你算"。两者选型标准：**要精确轨迹用写入，
要真实响应用力**。机械臂路径示教、镜头运镜、目标标记都是运动学写入
的典型场景。

## 小挑战（阶段 3 毕业挑战：低重力落点）
1. 笔算：月球 g=1.62 m/s²。估算方块的下落距离（默认配方起点 3 米，
   减去约半个方块的静置高度 0.5 米），用 t = √(2Δz/1.62) 算出预测值
2. 写下你的预测
3. 运行 `--moon`，对照实测触地时间（误差 ≤0.2 秒算命中；脚本用高度
   骤停检测触地——上一拍还在快速下落、这一拍停住即判定，不依赖方块尺寸）

## 常见问题
| 现象 | 修复 |
|---|---|
| "没有自由关节" | 你摆的物体是静态的；换默认配方的方块，或 spawn 一个 cube |
| 绕圈看起来一顿一顿 | 正常——每帧 0.01s 瞬移，视口 30fps 渲染下已接近连续；把 PERIOD 调大更平滑 |
| --moon 误差超 0.2s | 核对笔算的下落距离 Δz（起点高度减静置高度），回 16 课对照公式 |
| --moon 视口下落快慢和日志对不上 | 已知架构限制：重力修改仅本地物理生效（无远端下发通道），Studio 视口按独立物理状态渲染；以日志时间和触地判定为准 |
