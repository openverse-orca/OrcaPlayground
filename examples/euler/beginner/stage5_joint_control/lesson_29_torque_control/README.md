# 第 29 课：力矩控制

## 本课效果
终端先打印力矩旋臂的铭牌（ctrlrange ±5 N·m——限的是力矩本身），然后
发恒力矩 0.5 N·m：转速读数严格线性爬升，2 s 到 ≈3.0 rad/s，斜率
α 实测 1.50 = 理论 τ/I₀。随后给臂加 4/3 kg 配重（惯量加倍），同款
力矩再发一次：斜率精确减半（α = 0.75）——α = τ/I 的分子分母各动一次。

## 准备
同第 01 课（OrcaPlaygroundAssets 订阅，含力矩旋臂 rotor_torque）。
旋臂绕竖轴水平扫掠、悬浮摆放，全程无接触、无重力矩——理论干净。

## 运行
```bash
python -m examples.euler.beginner.stage5_joint_control.lesson_29_torque_control.run --default-scene
```

## 关键代码
ctrl 直接就是力矩（N·m，gear=1 免换算）：
```python
ctrl = sim_link.zero_ctrl(env)
ctrl[0] = 0.5                       # 0.5 N·m——没有伺服兜底，发多少是多少
env.do_simulation(ctrl, sim_link.FRAME_SKIP)   # ω 每步涨 α·dt，直线爬升
```
配重与复位（前面课程技能的合体）：`env.add_extra_weight({臂体名: 1.333})`
给臂加质量（等效钉在质心 0.5 m 处的点质量，I 增量 = Δm·(L/2)²）；
两幕之间用 26 课的上帝模式 `set_joint_qpos/qvel` 把旋臂复位归零。

## 动手改
配方区 `TORQUE_NM = 0.5` → `1.0`：斜率加倍（见小挑战）；
`SPIN_S = 2.0` → `4.0`：加速更久，末速翻倍、转角四倍（θ = ½αt²）。

## 解释结果
- **ω(t) 是直线**——三种电机里只有力矩控制给得出直线：位置伺服渐近
  趋近（27 课）、速度伺服指数爬升（28 课），恒力矩下 α 恒定，
  ω = α·t、θ = ½α·t²，伽利略的斜面换成旋转版
- **α = 1.50 = τ/I₀**——τ=0.5、I₀ = mL²/3 = 0.333（臂 m=1 kg、
  L=1 m，绕端点竖轴），实测斜率（线性拟合）与理论逐位吻合
- **加配重后斜率减半**——配重加在质心（0.5 m），I 增量 =
  Δm·(L/2)² = 4/3×0.25 = 0.333，恰好 I 加倍 → α = 0.5/0.667 =
  0.75。电机只认 τ/I：力矩是承诺，加速度是结果，中间隔着惯性
- **竖轴为什么重要**——绕竖轴重力矩为零，恒力矩下没有 sinθ 干扰；
  若换成水平摆（25 课机构），重力矩随角度变，ω(t) 不再是直线。
  19 课的积木臂也是这根竖轴——那时上帝模式掰关节，现在真力矩驱动

## 小挑战
组合预测（combine）：把 `TORQUE_NM` 改成 `1.0`（配重照加），
先预测两幕的斜率——
1. 基准幕（无配重）α 是多少？
2. 配重幕 α 是多少？和原来的基准幕比呢？
- 提示：τ×2、I 不变 → α₁ = 3.0；配重幕 τ×2 且 I×2 → α₂ = 1.5
  ——**分子分母同倍，商复原**：配重幕的斜率回到原基准幕的 1.50。
  力矩翻倍刚好抵消惯量翻倍
写下你的预测，运行对照两幕斜率。

## 常见问题
| 现象 | 修复 |
|---|---|
| 报错 nu=0 | 场景里的旋臂没有执行器——本课需要 rotor_torque（拖入或 --default-scene） |
| 斜率与理论差 >2% | 检查旋臂是否蹭到别的物体（默认悬浮不会）；确认场景里只有一个旋臂 |
| 配重读回质量没变 | 确认加在旋臂 body（body 名含 rotor）上，不是 mount |
| 视口里转太快看不清 | 0.5 N·m 末速约 3 rad/s（半圈每秒）；想慢点把 TORQUE_NM 调小 |
