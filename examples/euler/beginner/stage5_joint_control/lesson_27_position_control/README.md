# 第 27 课：位置伺服

## 本课效果
终端先打印执行器铭牌（数量、名字、ctrlrange ±1.57 rad），然后给摆发
两个目标角：45° 和 20°。摆自己爬升、站稳——但稳态角永远比目标小
一点：45° 目标稳态 ≈43.1°（静差 1.9°），20° 目标稳态 ≈19.0°
（静差 0.9°）。两档静差都与理论 mg·(L/2)·sinθ/kp 精确吻合。

## 准备
同第 01 课（OrcaPlaygroundAssets 订阅，含位置伺服摆 pendulum_position）。
注意：本课教具带**位置执行器**，与 25/26 课的被动摆不同。

## 运行
```bash
python -m examples.euler.beginner.stage5_joint_control.lesson_27_position_control.run --default-scene
```

## 关键代码
发指令——ctrl 写的是**目标角**，不是角度读数：
```python
ctrl = sim_link.zero_ctrl(env)
ctrl[0] = np.deg2rad(45.0)          # 目标角（弧度）——"请你去 45°"
env.do_simulation(ctrl, sim_link.FRAME_SKIP)   # 伺服自己出力走过去
```
对比 26 课：`set_joint_qpos` 是"动手掰到 30°"（说一不二），本课的
`ctrl` 是"请你去 45°"——执行器内部的弹簧（kp=100）把摆拉向目标、
阻尼（kv=8）保证不振荡，走多快、出多大力都由电机自己决定。

## 动手改
配方区 `TARGET_ANGLE_DEG = 45.0` → `30.0`：目标变低、重力矩变小，
静差缩小到 ≈1.3°；`WATCH_S = 4.0` → `2.0`：伺服收敛 <1 s，缩短观察
依然够用。

## 解释结果
- **稳态角 = 目标 − 静差**——P 弹簧靠误差吃饭：误差为零力矩就为零，
  摆立刻被重力拽回去。稳态时弹簧力矩恰好扛住重力矩：
  kp·δ = mg·(L/2)·sinθ，所以 δ = 4.905·sinθ/100
- **静差 1.9°（45° 档）**——sin(43.1°)×4.905/100 = 0.033 rad = 1.9°，
  实测与理论逐位吻合
- **两档静差比 ≈ 2.1**——sin 43°/sin 19° ≈ 2.1：目标越高负载越重，
  P 伺服偷的工越多。这就是为什么高精度机器臂要用更硬的弹簧（kp 更大）
  或更聪明的控制器（30 课的 PD）
- **ctrl 的单位语义会变**——本课 ctrl 是目标角（弧度）；28 课同一行
  ctrl 变成目标转速、29 课变成力矩。ctrlrange 只是取值范围，语义
  由执行器类型决定——读铭牌（本课开头）是每次换电机后的第一件事

## 小挑战
换目标角（swap）：把 `TARGET_ANGLE_DEG` 改成 `90.0` 运行——先猜两个问题：
1. 摆能到 90° 吗？（提示：ctrl=1.5708 rad，而 ctrlrange 上限是 1.57——
   超出部分会被**截断（clamp）**）
2. 静差是变大还是变小？大约多少度？（提示：sin 90° 是最大值 1）
- 参考答案：目标被 clamp 到 89.95°，稳态 ≈87.1°，静差 ≈2.8°——
  静差达到全行程最大（sinθ=1），「越到高处越扛不住」的极端版

**验收标准**
- [ ] 能说出 ctrl 与 set_joint_qpos 的区别（发目标 vs 改读数）
- [ ] 能解释静差的成因（P 弹簧靠误差产生力矩，稳态时与重力矩平衡）
- [ ] 能预测静差随目标角的变化（∝ sinθ，目标越高静差越大）
- [ ] 挑战：90° 目标的 clamp 行为与最大静差，实测对照

## 常见问题
| 现象 | 修复 |
|---|---|
| 报错 nu=0 | 场景里是被动摆——本课需要 pendulum_position（拖入或 --default-scene） |
| 稳态角与目标差好几度 | 正常——这就是静差；差的角度和理论值对上即通过 |
| 90° 挑战只到 89.95° | ctrlrange 截断（clamp），铭牌里看得见 ±1.57 的上限 |
| 摆爬升太快看不清 | 收敛 <1 s 是伺服本色；把 REPORT_INTERVAL_S 调到 0.05 看数字轨迹 |
| 场景里有其他执行器 | ctrl 按执行器顺序排列，本课写第 0 个；建议清理后重跑 |
