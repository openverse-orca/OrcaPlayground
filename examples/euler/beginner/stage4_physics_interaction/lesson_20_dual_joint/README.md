# 第 20 课：双关节协调

## 本课效果
积木臂要「摸到」斜前方的一个球，走了两次完全不同的路：第一次肩几乎
不动、光靠肘关节把前臂折进去；复位后第二次整条臂转身 100°、肘反向
折回——两次臂形截然不同，前臂末端却都精确停在球的位置。

## 准备
同第 19 课（OrcaPlaygroundAssets 订阅，含积木臂、球、桌子）。

## 运行
```bash
python -m examples.euler.beginner.stage4_physics_interaction.lesson_20_dual_joint.run --default-scene
```

## 关键代码
逆运动学：目标点 → 关节角（平面二连杆，余弦定理）：
```python
cos_t2 = (d*d - l1*l1 - l2*l2) / (2.0 * l1 * l2)   # 余弦定理定肘角
t2 = elbow_sign * math.acos(cos_t2)                  # ±两解（elbow_sign 选路）
t1 = phi_target - phi_inner                          # 肩角 = 目标方位 − 肘部内偏角
```
双关节协调驱动：两关节各按匀角速插值，同时起步、同时到达：
```python
qpos[qadr_shoulder] = w1 * t   # 肩角脚本
qpos[qadr_elbow]     = w2 * t   # 肘角脚本（w1 ≠ w2，速度各不同）
env.set_joint_qpos(qpos)
```
与 19 课的区别：19 课只写 1 个关节角；本课**两个关节同时动**，且角度
由数学解算（逆运动学）而非手拍脑袋——这是机械臂「指哪打哪」的内核。

## 动手改
配方区 `TARGET_X/TARGET_Y = -0.20/0.15` → `-0.28/0.21`（更远）：
臂要伸得更直（肘角从 99° 缩到约 49°）；
→ `0.0/0.38`（正前方极限）：几乎完全伸直（肘角只剩约 3°）。

## 解释结果
- **两条路肩/肘组合完全不同**——(肩 +6°, 肘 +99°) vs (肩 +100°, 肘 −99°)：
  余弦定理算肘角天然给出 ±两解（肘往左折或往右折），肩角随之配套
- **末端殊途同归**——两次实测到达点相差 < 5mm，各自距理论目标 < 1cm
- **球被顶开就是到达的现场证明**——路 A 前臂从上外侧压到球，路 B 整臂
  转身后前臂从另一侧到达，球两次都被推离路标点
- **为什么真实机械臂需要这套数学**——电机只能转关节，人只关心末端位置；
  逆运动学就是「末端位置 → 关节角」的翻译器；多解时按避障/限位/最短路选

## 常见问题
| 现象 | 修复 |
|---|---|
| 目标不可达 | 距离须在 0.015~0.385m 之间（臂伸展范围），太远/太近都无解 |
| 解超出关节限位 | 肩 ±110°、肘 ±130°——换目标点或换另一条路（elbow_sign） |
| 末端误差 > 2cm | 多半驱动了视口里手动拖入的旧臂实例——用 --default-scene |
| 球没被碰到 | 球不在目标点上（自摆场景）；末端仍会到达目标，看日志误差即可 |
| 视口里臂形和日志对不上 | 同上：确认驱动的是 arm_1（默认配方）而非残留实例 |
