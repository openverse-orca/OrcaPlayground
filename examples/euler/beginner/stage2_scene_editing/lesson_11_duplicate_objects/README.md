# 第 11 课：复制与排列

## 本课效果
三颗方块沿 X 轴整齐排成一排。改行列参数后重跑，自动生成整个阵列。

## 准备
- 同第 01 课（OrcaLab + OrcaPlaygroundAssets 订阅 + 首次重启）
- ⚠️ 本课**重建教学场景**：每次运行会清空场景再摆放（不是热编辑）

## 运行
```bash
python -m examples.euler.beginner.stage2_scene_editing.lesson_11_duplicate_objects.run
```

## 关键代码
`run.py` 顶部的**配方区**就是你要改的地方：
```python
# ======================= 配方区（改这里） =======================
ROWS: int = 1
COLS: int = 3
SPACING_M: float = 2.0
# ================================================================
```
`build_recipe()` 里的**双层循环**负责生成阵列：每个实例命名
`block_行_列`（如 `block_1_3`），位置按 `(列 - 中心) × 间距` 算出，
所以阵列永远以原点为中心展开。

## 动手改
把 `ROWS` 从 `1` 改成 `3`，重新运行——一排三颗变成 3×3 九宫格。

## 解释结果
- **实例唯一命名**是本课的核心：场景里每个实例都要有独一的名字，
  同名实例会互相顶替（还记得第 06 课吗？检索就是靠名字找人的）。
- 9 颗方块 = 9 行配方数据，但代码只有两层循环——**规律性的摆放
  交给循环，创造性的摆放才手写**。3×3 阵列在 5×5 m 地面上刚好铺开。

## 小挑战
把阵列改成 2 行 4 列（`ROWS=2, COLS=4`），先猜阵列会偏向原点的
哪一侧（提示：偶数列的「中心」不在格点上），再运行验证。

## 常见问题
| 现象 | 修复 |
|---|---|
| 方块穿插 | cube 原始尺寸 1 m，SPACING_M 需 ≥ 2 |
| 阵列跑出地面 | 地面 5×5 m；行列 × 间距太大就装不下了，减行列或缩间距 |
| 只有部分方块出现 | 行列数乘错或名字重复；检查 ROWS/COLS 和循环里的命名 |
