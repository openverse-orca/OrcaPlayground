# 第 25 课：认识关节

## 本课效果
终端先打印摆的「关节铭牌」——名字、挂载 body、类型、qpos/dof 地址；
静读时角度 0°、角速度 0（与视口一致）。随后对摆施加一个水平脉冲
（2.4 N × 0.3 s，力臂在杆中部），摆起振到 ~15°，终端每 0.2 s 打印
一次实时角度与角速度：角度过零时角速度绝对值最大，峰值角处
角速度 ≈ 0。

## 准备
同第 01 课（OrcaPlaygroundAssets 订阅，含单摆教具 pendulum_passive）。

## 运行
```bash
python -m examples.euler.beginner.stage5_joint_control.lesson_25_inspect_joint.run --default-scene
```

## 关键代码
控制的前提是先看清对象——用自省 API 读关节档案：
```python
joint_name, qadr, vadr = sim_link.resolve_hinge_joint(env, pendulum_body)  # 名字/地址
q   = float(np.asarray(env.data.qpos).copy()[qadr])   # 角度（弧度）
w   = float(np.asarray(env.data.qvel).copy()[vadr])   # 角速度（rad/s）
```
起摆用的是 21 课学过的外力（`apply_body_force`），本课不引入任何
新的写入手段——**只读**。角度 qpos 和角速度 qvel，就是阶段 5 后面
五课要控制的两样东西。

## 动手改
配方区 `NUDGE_FORCE_N = 2.4` → `4.8`：冲量矩加倍，起摆角速度加倍，
摆幅约翻倍（≈30°，仍能看到清晰的过零/峰值节奏）；`REPORT_INTERVAL_S
= 0.2` → `0.05`：读数密度提高 4 倍，能量交换的细节更清楚。

## 解释结果
- **静止读数全 0**——摆自然下垂，角度零点就是竖直位置；读数与视口
  一致是「读对了」的最低验收
- **过零时角速度最大、峰值处角速度 ≈ 0**——单摆能量守恒：最低点
  全部能量是动能（速度最大），最高点全部换成势能（速度为零）。
  过山车冲到底部最快、荡秋千到最高点瞬间悬停，是同一个道理
- **峰值角 ≈ 15°**——力施加在摆体质心（杆中部，力臂 0.5 m），冲量矩
  = F·t·r ≈ 0.36 N·m·s，起摆角速度 ω₀ ≈ 1.06 rad/s，摆幅由能量守恒
  mgL_com(1−cosθ_max) = ½Iω₀² 解出
- **为什么先学读**——26 课写状态、27–29 课写控制量、30 课写 PD，
  全部以「读当前角度/速度」为第一步；反馈控制的「反馈」，就是
  本课这两个读数

## 小挑战
换一个关节读（swap）：默认配方 spawn 的场景里还有一个 `{实例名}_mount`
body（摆的支架），它挂的是**自由关节**（free joint）。把 `run_inspect`
里的 `pendulum_body` 换成 mount 的 body 名运行——看看自由关节的 qpos
读数和铰链有什么不同？
- 提示：铰链 1 个 qpos 槽（角度）；自由关节 7 个槽（3 位置 + 4 四元数），
  这是 26 课写状态时「全量数组」长什么样的伏笔

**验收标准**
- [ ] 能说出 qpos 读的是角度（弧度）、qvel 读的是角速度（rad/s）
- [ ] 能解释过零角速度最大、峰值角速度为零（动能/势能交换）
- [ ] 挑战：读出 mount 的自由关节，说出铰链与自由关节 qpos 槽位差异

## 常见问题
| 现象 | 修复 |
|---|---|
| 未找到单摆 | 场景里要有 pendulum_passive（拖入或 --default-scene） |
| 读数一直是 0 | 确认视口里摆真的被推动了——演示期间请勿拖拽其它物体 |
| 摆动越来越慢 | 正常（极轻微数值阻尼）；也检查是否在视口里持续碰到了摆 |
| 角度显示跳变 ±180° | 摆越过竖直上方的大回旋（力太大），把 NUDGE_FORCE_N 调回 1.1 |
