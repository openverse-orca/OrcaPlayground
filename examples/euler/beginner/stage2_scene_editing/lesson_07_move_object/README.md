# 第 07 课：移动物体

## 本课效果
方块沿 X 方向移到指定位置。修改配方区数字后重跑，位置立即变化。

## 准备
- 同第 01 课（OrcaLab + OrcaPlaygroundAssets 订阅 + 首次重启）
- ⚠️ 本课**重建教学场景**：每次运行会清空场景再摆放（不是热编辑）

## 运行
```bash
python -m examples.euler.beginner.stage2_scene_editing.lesson_07_move_object.run
```

## 关键代码
`run.py` 顶部的**配方区**就是你要改的地方：
```python
# ======================= 配方区（改这里） =======================
BLOCK_POSITION: tuple[float, float, float] = (0.5, 0.0, 0.5)
# ================================================================
```

## 动手改
把 `0.5` 改成 `1.0`，重新运行，观察方块沿 X 方向移远半米。

## 解释结果
这是「编辑配方 → 重建」：你改的是 spawn 参数（初始摆放），不是运行时推动物体。
两者区别要到后续的动力学课程（第 21 课臂式推放：臂推 vs 直接施力）才会正面对比。

## 小挑战
让方块同时向 X 和 Y 各移动 0.5 米。

## 常见问题
| 现象 | 修复 |
|---|---|
| 位置没变 | 确认改的是配方区常量并保存；重跑即重建场景 |
| 物体消失了 | 位置可能超出视口范围；改回 (0.5, 0.0, 0.5) |
