# 预编译示例插件

本目录只包含版本固定的厂商包：`provider.json`、输入输出契约、型号资产、Linux x86_64 动态库、
许可证及包说明。没有 Host、契约工具或 C/C++ 算法源码。
Host 由支持平台的官方 OrcaGym 安装包提供并自动加载，用户不必单独安装或指定库路径。

`manifest.json` 记录 SDK/ABI、原始构建来源和逐文件 SHA256；它用于复现和完整性检查，不是签名
或来源认证。应用只应加载可信插件，同进程原生代码不具备进程级崩溃隔离。

首次发布的四个示例包版本与 `sdk_version` 均为 `1.0.0`，使用同一套 SDK 契约解释规则。
`sdk_version` 是插件面向的 SDK 版本，不是 OrcaGym 的安装版本。C ABI 版本仍为 `2`，
与 SDK 发布版本独立编号；兼容性由 OrcaGym 的运行时校验。

当前演示仅面向经发布验收的 Linux x86_64 环境，具体系统兼容范围以 OrcaGym 发布说明为准。
其他系统可查看 XML 和 Python 源码，但需平台匹配的插件与
Host 才能运行算法；这不限制 OrcaGym 的其他功能。

各子包 README 随原始厂商包保留并受清单校验，其中的编译段落仅适用于 SDK 开发者，
不是 Playground 安装步骤。算法维护、版本更新及开发文档入口见 [开发者说明](../developer.md)。
