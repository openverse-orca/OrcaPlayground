# 第 26 课：写关节状态（上帝模式）

## 本课效果
上帝模式把摆「掰」到 30° 按住，然后放手——摆从 30.0° 起振，第一峰
回到 ≈30°（无阻尼能量守恒），大摆周期实测 ≈1.67 s。终端持续打印
角度/角速度读数，节奏与 25 课同款：过零动能最大、峰值势能最大。

## 准备
同第 01 课（OrcaPlaygroundAssets 订阅，含单摆教具 pendulum_passive）。

## 运行
```bash
python -m examples.euler.beginner.stage5_joint_control.lesson_26_set_joint_pose.run --default-scene
```

## 关键代码
写状态 = 直接改引擎的账本（角度读数本身）：
```python
qpos = np.asarray(env.data.qpos).copy()   # 全量数组（25 课挑战的 7 槽伏笔）
qpos[qadr] = np.deg2rad(30.0)             # 只改摆这一个槽
env.set_joint_qpos(qpos)                  # 掰到 30°
qvel = np.asarray(env.data.qvel).copy(); qvel[vadr] = 0.0
env.set_joint_qvel(qvel)                  # 按住不动（角速度清零）
```
这就是阶段 4 一直在用的写法（19 课肩关节扫掠、肘钳定），本课正式
命名：**上帝模式**。它的特点是说一不二——不经过任何力，没有反作用、
没有对抗；代价是现实中不存在这样的手（21 课肘被球反踢弯只能每帧
重写钳定，就是在硬补上帝模式的窟窿）。**上帝模式只改初始状态，
放手之后的物理是真实的**——第一峰回到 30° 就是证据。

## 动手改
配方区 `INITIAL_ANGLE_DEG = 30.0` → `90.0`：摆被掰到水平再放手
（见下面小挑战）；`WATCH_S = 8.0` → `12.0`：多看几个周期，周期
测量更稳。

## 解释结果
- **放手瞬间摆从 30.0° 起振**——写入的 qpos 就是初始状态，回读分毫不差
- **第一峰回到 ≈30°（±0.3°）**——无阻尼单摆能量守恒：上帝模式没有
  （也不能）修改物理定律，它只是设定了开场
- **周期 1.67 s > 小摆周期 1.64 s**——大摆非线性修正：振幅越大荡得
  越慢，T = T₀(1+θ₀²/16+…)。30° 时 +1.7%，刚好可测
- **为什么必须全量数组**——set_joint_qpos 写的是整条状态数组（25 课
  挑战里自由关节的 7 个槽：3 位置 + 4 四元数），Euler 体系不收单个
  关节的 dict，先 copy 再改槽是标准姿势

## 小挑战

水平再放手），两件事——
1. 第一峰还会回到 90° 吗？
2. 周期还是 1.67 s 吗？变大、变小还是不变？大约多少？

  里 θ₀ 变成 π/2——修正项从 +1.7% 涨到 +16%，周期 ≈1.90 s

## 常见问题
| 现象 | 修复 |
|---|---|
| 未找到单摆 | 场景里要有 pendulum_passive（拖入或 --default-scene） |
| 摆幅缓慢衰减 | 轻微数值阻尼属正常；明显衰减检查视口是否碰到摆 |
| 90° 挑战时摆过头转圈 | 90° 恰好是分界：能量刚好够到顶点，数值误差可能让它翻过去——翻圈也验证了能量守恒（转到另一侧 90°） |
| 写入后视口没动 | 正常：放手循环开始后 render 才把状态推给视口 |
